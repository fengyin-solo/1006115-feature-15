# 盾构隧道掘进施工管理平台

面向盾构机台账、掘进环次、管片拼装、同步注浆、渣土外运、地表沉降监测与轴线纠偏的一体化盾构隧道施工管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。浆液拌制的配方
（`mortar-recipes`）、判定标准版本（`mortar-standards`）、配料核对记录（`mortar-checks`）
也存在同一份 localStorage 里。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 浆液拌制配料偏差核对

每个浆液批次把**配方用量、现场签认实际投料、领料单数量**三处取数收成同一条批次记录，
核对结论只产一份（`mortar-checks`），试验检测委托清单与同步注浆待用批次清单都从这份结论投影，
两处入口读到的偏差批次同号、同条数。

- **判定线（四条，任一不过即核对不合格，不许提交检验，消息逐条写明差在哪一项）**
  - 水泥用量：实投相对配方总量偏差 ±5%
  - 膨润土用量：实投相对配方总量偏差 ±5%
  - 水灰比：与设计值极差 ±0.05
  - 稠度：与设计值极差 ±20mm
- **取数以哪份为准**：实际投料、水灰比、稠度一律以拌制现场当班签认记录为准；
  领料单只作月度总量备核，与现场记录打架时不改判。
- **标准版本化**：判定标准按拌制日期适用；负责人调整标准只追加新版本（生效日期必须更晚），
  已冻结的核对结论不随后续调标改动，早先批次按当时版本留档；调标后会把缺结论的已拌制批次重核一遍。
- **重复提交**：同一批次核对只留最早一条，再递一遍沿用最早结论；数据不齐时不写半条记录。
  批次、核对记录、自动生成的试验委托一次原子落库。
- **老批次补登**：打开浆液拌制/试验检测/同步注浆任一页时，自动按拌制日期补登；
  负责人也可在浆液拌制页手工触发。
- **权限**：配方与判定标准只有顶栏切到「拌制站负责人」后可改。
- 待用批次清单只列「检验合格 + 核对合格」的批次；未核对或偏差超标的批次不能开始注浆。
- 领域逻辑冒烟测试：`npm run smoke`（14 组断言，含判定线、冻结、补登、调标、两处同源）。

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 配料偏差核对的判定、冻结、补登、权限与两处清单投影集中在
  `frontend/src/api/mortar-check.ts`，`local-service.ts` 只做收口，页面不做业务判断。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `shield-tunnel-construction:entries` 这一项，或调用 `resetModule(模块)`。
